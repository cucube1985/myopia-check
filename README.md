# 우리 아이 근시 테스트

만 5–18세 아이의 굴절검사값(SPH·CYL)으로 근시 정도와 한국 또래 대비 위치를 살펴보는 교육·상담 보조용 프로토타입입니다.

**웹에서 바로 쓰기:** https://cucube1985.github.io/myopia-check/

> 교육 및 상담 보조용입니다. 조절마비 굴절검사와 안과 전문의 평가를 대신하지 않습니다. 백분위는 정규분포를 가정한 근사값이며 진단이나 미래 예측이 아닙니다.

## 기능

- 양안 SE(= SPH + CYL ÷ 2) 계산, 근시 단계 분류, 연령별 또래 비교 그래프
- 검사 방식(조절마비·비조절마비·안경 처방) 차이를 범위로 표시
- 추적 관찰: 이전 검사를 넣으면 연간 변화(D/년, 안축장 mm/년) 자동 계산
- 아이별 기록 저장(기기·브라우저 안), 백업 파일 내보내기/가져오기(선택 암호화)

## 개인정보

서버가 없습니다. 계산과 저장은 모두 사용자의 브라우저(또는 Android 앱) 안에서 이루어지며 입력값은 어디에도 전송되지 않습니다. 웹 버전의 저장 기록은 그 브라우저에만 남으므로 브라우저 데이터를 지우면 함께 사라집니다. 필요하면 «백업 파일 만들기»를 쓰세요.

## 기준 자료

연령별 참고 분포는 Kim DH 외, *Scientific Reports* (2026), 보충표 1의 일반인 KNHANES 2016 표본(n = 1,224, 비조절마비 자동굴절검사, 더 근시인 눈)입니다. [doi:10.1038/s41598-026-53576-3](https://doi.org/10.1038/s41598-026-53576-3)
